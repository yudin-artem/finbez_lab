# Обнаружение аномалий в финансовых транзакциях

## Задача
Сравнить 5 методов обнаружения подозрительных транзакций (статистический, ансамблевый, плотностной, кластерный и нейросетевой) и supervised-эталон (Random Forest) на открытых обезличенных данных.

## Данные
Основной: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) (284 807 транзакций, 492 фрода; после удаления дубликатов 283 726 и 473). Скачать `creditcard.csv` в папку `data/`.

## Запуск
```bash
pip install -r requirements.txt
jupyter notebook anomaly_detection.ipynb   # или загрузить в Google Colab
```
Настройки собраны в классе `Config` (первая ячейка). Полный прогон занимает около 1–1,5 часа.

## Структура
```
├── anomaly_detection.ipynb   # весь пайплайн
├── requirements.txt
├── data/                     # creditcard.csv (не коммитить)
└── results/                  # metrics_*.csv, tuning.csv, ablation.csv, графики
```

## Результаты
(заполнить после запуска на реальных данных: таблицы из `results/metrics_summary.csv` и `results/metrics_time_split.csv`)

## План реализации
| Этап | Что делаем | Результат |
|------|-----------|-----------|
| 1. Постановка | Цель, метрики (PR-AUC, Recall/Precision при бюджете проверки), гипотезы | текст отчёта |
| 2. Данные | Скачать датасет, удалить дубликаты, EDA, дисбаланс | графики |
| 3. Предобработка | RobustScaler, отсечение хвостов, split (случайный + по времени) | воспроизводимый пайплайн |
| 4. Методы | Robust Mahalanobis, IForest, LOF, K-means, Autoencoder, RF (эталон) | 5 детекторов + эталон |
| 5. Оценка | PR/ROC, Recall/Precision@бюджет, 5 разбиений (20 для быстрых методов), время | таблица сравнения |
| 6. Углубление | Подбор гиперпараметров, абляция (Time, log1p, отсечение), разбиение по времени, анализ ошибок | доп. эксперименты |
| 7. Выводы | Рекомендации по выбору метода | текст отчёта |
| 8. Оформление | Сохранить ноутбук с результатами, README, отчёт и презентация | загрузка файлов |
