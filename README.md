# Обнаружение аномалий в финансовых транзакциях

## Задача
Сравнить 5 методов обнаружения подозрительных транзакций (статистический, ансамблевый, плотностной, нейросетевой и supervised-baseline) на открытых обезличенных данных.

## Данные
Основной: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) (284 807 транзакций, 492 фрода). Скачать `creditcard.csv` в папку `data/`.
Без файла ноутбук запускается на синтетических данных (только для проверки скелета).

## Запуск
```bash
pip install -r requirements.txt
jupyter notebook anomaly_detection.ipynb   # или загрузить в Google Colab
```

## Структура
```
├── anomaly_detection.ipynb   # весь пайплайн
├── requirements.txt
├── data/                     # creditcard.csv (не коммитить)
└── results/                  # metrics.csv, графики
```

## План реализации
| Этап | Что делаем | Результат |
|------|-----------|-----------|
| 1. Постановка | Цель, метрики (PR-AUC, Precision@k, F1), гипотезы | раздел «Обзор» |

| 4. Методы | Mahalanobis, IForest, LOF, Autoencoder, RF | 5 детекторов |
| 5. Оценка | PR/ROC, Precision@k, матрицы ошибок, время | таблица сравнения |
| 6. Углубление | Подбор гиперпараметров, 2-й датасет, SHAP, стоимостная метрика | доп. эксперименты |
| 7. Выводы | Рекомендации по выбору метода | раздел «Выводы» |
| 8. Оформление | Сохранить ноутбук с выводами, README, отчёт и презентация | загрузка файлов |
